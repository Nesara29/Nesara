# 🎉 Event Management System (EMS)

A full-stack **Event Management System** developed using **Java**, **Spring Boot**, **Spring MVC**, **Thymeleaf**, **Spring Data JPA**, and **MySQL**. The application simplifies event planning and management by providing an organized platform for managing events, registrations, schedules, and participants.

---

## 📖 Overview

The **Event Management System (EMS)** is a web-based application that helps organize and manage events efficiently. It enables administrators to create events, manage participants, maintain event schedules, and monitor registrations through an intuitive web interface.

This project demonstrates enterprise web application development using the Spring Boot ecosystem and follows the MVC architecture.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/EMS.git
```

### 2. Navigate to the Project

```bash
cd EMS
```

### 3. Configure the Database

Create a MySQL database and update the connection details in:

```text
src/main/resources/application.properties
```

### 4. Build the Project

```bash
mvn clean install
```

### 5. Run the Application

```bash
mvn spring-boot:run
```

or

```bash
./mvnw spring-boot:run
```

### 6. Open the Application

```text
http://localhost:8080
```
